# 变频器控制系统（V1.4.0）

## 说明

这是一个用于控制变频器（及其配套的步进电机）的 C# 上位机程序，采用 .NET Framework 4.8 框架。

## 主要功能说明

1. **启动/停止**

   启动控制按钮及左侧指示灯，点击后进行初始化。初始化完成后，开始按照刷新间隔轮询读取。

2. **映射设置**

   连接参数保存在程序目录下的 `Config/connection.json`，启动时自动读取。默认配置沿用 192.168.0.201–192.168.0.208 共 8 个 IP，每个 IP 对应 32 个端口（5001–5032），共 256 个通道。修改 JSON 后重启程序即可生效；部署时需将 `Config` 目录与程序一起复制。配置缺失或无效时，程序会显示错误并退出。

   `ipAddresses` 按通道组顺序填写，`portsPerIp` 是每个 IP 的端口数，`startPort` 是每组的起始端口。总通道数由 IP 数量乘以 `portsPerIp` 自动计算，不需要另设数量。导入 CSV 时，超出当前总通道数的记录会被跳过。

3. **导入配置**

   打开 CSV 文件，读取相应信息存入底层 `database`。CSV 格式如下：

   | channel | enable | opposite | forward | backward |
   | --- | --- | --- | --- | --- |
   | 0 | TRUE | FALSE | 50 | 20 |
   | 1 | TRUE | TRUE | 20 | 50 |
   | 2 | TRUE | FALSE | 50 | 20 |
   | 3 | TRUE | TRUE | 20 | 50 |

4. **选择配置**

   将当前底层 `database` 数据显示在 UI 中以供修改，具有批量修改功能；批量修改也可以通过修改 CSV 文件的方式操作。

5. **保存配置**

   将当前底层 `database` 数据存入选择的 CSV 文件中，关闭窗口时如未保存会提示进行保存。

6. **变频器运行**

   支持正转、反转、停止运行功能。不允许在正转状态下直接切换到反转。

7. **刷新间隔**

   单位为毫秒。

8. **变频器初始化**

   暂不开放。主要用于将变频器的频率输入来源和命令输入来源由面板改为上位机。对每一个变频器需要且仅需要执行一次，如有更换变频器的需要请联系作者。

9. **频率写入**

   按照当前“选择配置”界面的频率值，将所有启用变频器的频率写入底层 `database`。需要注意：如果正反转 `opposite` 开启，则正转频率写入会写入反转频率，反之亦然。

10. **变量查询**

    支持多种变量查询，通过下拉框选取后，轮询过程中读取对应变量并更新在图上。

11. **日志记录**

    支持日志同步保存到本地路径目录中。

12. **图表控制**

    支持图表缩放，拖动平移，双击恢复显示全部数据
